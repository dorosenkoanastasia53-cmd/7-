# Лендинг «Чорна пʼятниця» — Метаморфоза

Звичайні файли: `index.html` + `img/`. **Можна просто перетягнути папку на Netlify** (Deploys → drag & drop), GitHub не потрібен.

## Як працюють заявки і статистика
Сторінка надсилає їх через **основний сайт** (psy-centr-kyiv-morphosis.netlify.app), де вже налаштований бот:
- **заявки** → той самий Telegram-бот, що й заявки з основного сайту;
- **статистика** (джерела, час на сторінці, кнопки) → основний сайт `/admin` → «Відвідування сайту».
  Події лендингу підписані «BF: …».

Адреса основного сайту — у `index.html`, змінна `MAIN_SITE`.

## Додаткова аналітика (за бажанням) — у `index.html`, вгорі блоку <script>
- `CLARITY_ID` — Microsoft Clarity (безкоштовно): записи сесій, теплові карти кліків, час, джерела.
  Зареєструйтесь на clarity.microsoft.com → New project → скопіюйте ID проєкту.
- `META_PIXEL_ID` — піксель Meta, щоб реклама в Instagram оптимізувалась на заявки.
- `GA4_ID` — Google Analytics 4.
