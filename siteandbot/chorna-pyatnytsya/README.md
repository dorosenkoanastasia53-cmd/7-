# Лендинг «Чорна пʼятниця» — Метаморфоза

Окремий сайт під рекламу в Instagram: сторінка, заявки в Telegram-бот і власна статистика.

| Файл | Що це |
|---|---|
| `index.html`, `img/` | сама сторінка |
| `stats/` | статистика: переходи, джерела, реклама (utm), час, кнопки, воронка, запити, фахівці |
| `netlify/functions/send.js` | надсилає заявку в Telegram через бота |
| `netlify/functions/track.mjs` | збирає статистику (Netlify Blobs, анонімно) |

## Запуск на Netlify
Функції працюють лише при публікації **через GitHub** (або Netlify CLI), не через перетягування папки.

1. Netlify → Add new site → Import from GitHub → репозиторій `7-`,
   **Base directory:** `siteandbot/chorna-pyatnytsya`.
2. Site settings → Environment variables:
   - `BOT_TOKEN` — токен бота від @BotFather (той самий, що на основному сайті)
   - `ADMIN_CHAT_ID` — ваш Telegram id, куди приходять заявки
   - `STATS_PASSWORD` — будь-який пароль для сторінки статистики
3. Перевірка: залиште тестову заявку → вона має прийти в Telegram;
   відкрийте `/stats`, введіть пароль → побачите свій візит.

## Посилання для реклами
`https://<адреса-сайту>/?utm_source=ig&utm_content=<назва_креативу>` —
тоді в статистиці видно, яка саме реклама привела людей і заявки.

## Що налаштувати в index.html (вгорі блоку <script>)
- `META_PIXEL_ID` — ID пікселя Meta, щоб реклама оптимізувалась на заявки
- `INSTAGRAM_URL` — краще `https://ig.me/m/<нікнейм>`
- `PROMO` — дати акції; після 30.11 сторінка сама показує звичайну знижку −20%
