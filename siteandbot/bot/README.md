# Бот Анастасії Дорошенко

Меню з вибором: **Консультація / Матеріали / Хочу на марафон / Маю питання**.
Оплата матеріалів — ручна (картка monobank) з підтвердженням адміністратором.

## Що вміє бот

- **📅 Консультація** — показує формати й ціни + кнопки написати в Telegram/Instagram
- **📚 Матеріали** — вебінар (499 грн) і зошит «Я у стосунках» (370 грн):
  оплата на картку → клієнт надсилає скрін → ви підтверджуєте → бот сам видає файли
- **🎯 Хочу на марафон** — клієнт лишає свій тег/телефон, заявка приходить вам, ви звʼязуєтесь вручну
- **💬 Маю питання** — клієнт пише запитання, воно пересилається вам

Deep-links із сайту працюють одразу:
`?start=webinar`, `?start=workbook`, `?start=marathon`.

**Важливо:** матеріали надсилаються клієнту **лише після того, як ви натиснете
«✅ Підтвердити»**. Без вашого підтвердження файли не видаються.

**Активність і статистика:** кожна оплата, заявка на марафон і питання
одразу приходять вам у Telegram. Команда **`/stats`** (доступна лише вам)
показує зведені цифри: заявок на оплату, підтверджених продажів, заявок на
марафон і питань. Цифри зберігаються у `bot/stats.json`.

## Що заповнити перед запуском (вгорі `bot.py`)

| Змінна | Що це |
|---|---|
| `BOT_TOKEN` | Токен від [@BotFather](https://t.me/BotFather) → ваш бот → *API Token* |
| `ADMIN_ID` | Ваш Telegram id ([@userinfobot](https://t.me/userinfobot)). Зараз стоїть `507173671` — перевірте |
| `CARD_NUMBER` | Уже вписано: `4441 1144 4701 5536` |
| `PRODUCTS["workbook"]["delivery"]` | Перевірте посилання на платний зошит |

Посилання на матеріали вебінару вже вставлені (запис, презентація, зошит-шаблон).

## Запуск

```bash
cd bot
pip install -r requirements.txt
python bot.py
```

Щоб бот працював постійно — розмістіть його на хостингу (Railway, Render, VPS)
і тримайте процес запущеним. Можу підказати покроково.

> Стан діалогу зберігається в памʼяті процесу. Якщо бот перезапустити в момент
> очікування скріна — клієнту достатньо ще раз натиснути «Я оплатив(ла)».
