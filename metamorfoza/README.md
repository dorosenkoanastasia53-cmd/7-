# Метаморфоза — сайт оренди кабінетів

Односторінковий сайт: кабінети й ціни, знижки, фото, форма заявки,
переваги, умови, питання. Заявки з форми надходять у Telegram через бота.

## Як опублікувати на Netlify

Форма заявки працює через Netlify-функцію (`netlify/functions/send.js`),
тому сайт треба публікувати **через GitHub** (як ваш основний сайт) або через
Netlify CLI. Якщо просто перетягнути папку в Netlify Drop, сторінки відкриються,
але заявки не надсилатимуться (кнопки Telegram / Instagram працюватимуть).

1. Завантажте вміст цієї папки в репозиторій на GitHub.
2. Netlify → Add new site → Import an existing project → GitHub → оберіть репозиторій.
   Якщо папка `metamorfoza` лежить не в корені — вкажіть її в полі **Base directory**.
3. Netlify → Site configuration → **Environment variables** → додайте:

| Змінна | Що це |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота від @BotFather |
| `ADMIN_CHAT_ID` | Ваш Telegram id (дізнатися: напишіть @userinfobot). Кілька отримувачів — через кому |
| `STATS_KEY` | Пароль до сторінки статистики `/stats.html` (придумайте самі) |

4. **Deploys → Trigger deploy**.
5. Кожен отримувач має **один раз написати боту /start** — інакше Telegram не дасть
   боту надсилати повідомлення.
6. Перевірте: заповніть форму на сайті — заявка має прийти в Telegram.

## Що можна змінити

- **Посилання на Telegram / Instagram** — у `index.html`, об'єкт `LINKS` на початку скрипту.
- **Фото** — папка `img/`. Картки кабінетів: `small.jpg`, `big.jpg`, `hall.jpg`.
  Фото першого екрана — `big-sofa.jpg` (Великий кабінет з диваном).
  Галерея також підхоплює `hall-2.jpg`, `hall-4.jpg`, `small-3.jpg`,
  `lounge.jpg` — просто покладіть файли
  з такими назвами. Підписи й порядок — масив `GALLERY` у `index.html`.
  Фото, якого немає в папці, просто не показується.
- **Ціни, години роботи (08–22), свята** — `pricing.js`, об'єкт `CONFIG`.

## Статистика

Сторінка **`ваш-сайт/stats.html`** (вхід за паролем `STATS_KEY`) показує:
відвідувачів і перегляди по днях, звідки приходять люди, скільки надіслали
заявку або перейшли в Telegram / Instagram, які приміщення цікавлять,
телефон чи комп'ютер. Дані анонімні, зберігаються в Netlify Blobs
(вмикається автоматично). Боти й пошукові роботи не враховуються.

Щоб бачити окремо, звідки прийшли люди, додавайте до посилання мітку:
`ваш-сайт/?utm_source=instagram`, `?utm_source=stories`, `?utm_source=flyer`.
